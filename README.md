# Todo List React

A modern, feature-rich Todo List application built with React, TypeScript, and Tailwind CSS. This application provides a beautiful and intuitive interface for managing your daily tasks with advanced features like drag-and-drop reordering, filtering, sorting, and more.

## 🌟 Features

- ✨ Modern and responsive UI with Tailwind CSS
- 🎯 Drag and drop reordering of tasks
- 🔍 Search functionality
- 📅 Due date management
- ✅ Task completion tracking
- 📊 Filtering options (All, Active, Completed, Has Due Date)
- 📈 Sorting by creation date or due date
- 🔄 Toggle sort order (ascending/descending)
- 📱 Mobile-friendly design
- 🎨 Beautiful animations and transitions
- 🎯 Bulk actions (Select All, Delete Selected)

## 🛠️ Technologies Used

- React 19
- TypeScript
- Tailwind CSS
- @dnd-kit (Drag and Drop)
- Radix UI Components
- Font Awesome Icons
- date-fns
- React Router DOM
- Vite
- Nx

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Trung112277/todo-list-react.git
cd todo-list-react
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm start
# or
yarn start
```

4. Open your browser and visit `http://localhost:4200`
